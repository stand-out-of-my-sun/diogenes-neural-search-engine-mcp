## Connection Options

### 1. Remote Streamable HTTP (Recommended)
Add directly to your MCP client config (Cursor, Claude Desktop, Windsurf, Zed):

```json
{
  "mcpServers": {
    "neural-search-engine": {
      "url": "https://diogenes-micro-gateway.corinth.workers.dev/mcp/neural-search-engine",
      "transport": "streamable-http"
    }
  }
}
```

### 2. Local Stdio Bridge
Install and run via npx:

```bash
npx @stand-out-of-my-sun/diogenes-neural-search-engine-mcp
```
